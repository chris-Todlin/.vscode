# WebSocket Chat – Step Checklist

## Backend (server) steps

```
[Done] Install dependencies
    - install Express
    - install ws

[Done] Create an Express server

[Done] Create an HTTP server from Express

[Done] Attach a WebSocket server to the HTTP server

[Done] Handle WebSocket connections
    - when a client connects, a WebSocket object (ws) is created

[ ] Wait for client login
    - client sends userId

[ ] Store connected users
    - save userId + socket connection in an array

[ ] Handle incoming messages
    - read receiver
    - find receiver in user list
    - send message through receiver socket

[ ] Handle disconnections
    - remove user from the user list
```

---

# Frontend (client) steps

```
[ ] Create a WebSocket connection to the server

[ ] Send login message after connecting
    - include userId

[ ] Send chat messages
    - include receiver
    - include message text

[ ] Listen for incoming messages from the server

[ ] Display received messages in the chat UI
```

# Identifying the Sender (Server Logic)

Important rule:

```
Never trust the client for sender identity.
```

Instead store the **userId inside the socket**.

Example:

```javascript
const users = [];

wss.on("connection", (ws) => {

  ws.on("message", (data) => {
    const msg = JSON.parse(data);

    // user login
    if (msg.type === "login") {

      ws.userId = msg.userId;

      users.push({
        userId: msg.userId,
        socket: ws
      });
    }

    // message sending
    if (msg.type === "message") {

      const receiver = users.find(u => u.userId === msg.receiver);

      if (receiver) {
        receiver.socket.send(JSON.stringify({
          sender: ws.userId,
          message: msg.message
        }));
      }

    }

  });

});
```

Key idea:

```
sender = ws.userId
```
