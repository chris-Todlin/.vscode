01
Define User Schema
Create a Mongoose schema with a role field to distinguish users.

models/User.js

Include fields: username, password, role

Set role default to 'user'

Use enum: ['user','author','admin'] for clarity

02
Seed Initial Admin
Bootstrap Account
Insert a default admin user directly into MongoDB when setting up the system.

Mongo shell or seed script

Hash the password with bcrypt

Insert document: { username: 'rootAdmin', password: <hashed>, role: 'admin' }

Ensure only one admin is seeded

03
Configure Passport Serialize/Deserialize
Make sure Passport stores user ID in session and fetches role on deserialize.

passport.js

serializeUser: store user.id

deserializeUser: fetch user from DB → includes role

04
Build Role Middleware
Create middleware to check roles before allowing access to routes.

middleware/authorizeRoles.js

Function takes allowed roles

Compare req.user.role against allowed list

Return 403 if not authorized

05
Admin Dashboard Role Management
Allow admin to promote users to authors via dashboard routes.

routes/admin.js

Route: POST /admin/promote/:id

Find user by ID

Update role to 'author'

Save changes

06
User and Author Access
Define routes with role checks for blog, comments, and interactions.

routes/blog.js

Users: read blogs, comment

Authors: create/update own blogs

Admin: delete any blog, manage users
